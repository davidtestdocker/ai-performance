# 一次只教一小步

[課綱](ROADMAP.md)｜[代理規則](../AGENTS.md)

每天時間參考：觀念 20–30 分鐘、逐步實作 60–120 分鐘、驗收與複習 20–30 分鐘。這不是硬性時限；不懂就停留練習，尤其 Slurm 初次環境配置可延長，不重排週次目標。

## 對話節奏

1. 讀進度並說明這一小步解決哪個工作問題。
2. 用小例子解釋新名詞、語法和預期結果，不假設已懂。
3. 明確指出在哪台 VM、哪個目錄執行，以及資源或設定影響。
4. 只給一條命令或一小段修改。複合微步驟仍要再拆小。
5. 等學員回傳完整輸出或程式，再核對正確性、錯誤、單位與量測範圍。
6. 請學員解釋或先預測一個小變化再驗證；通過後記錄並前進。

## 每日交付

固定 day README 已有精簡複習與兩題中文參考問答。收尾時再把當日「問題、實際命令、必要輸出、判讀、三句中文複習、兩題問答作答、未解問題」寫入 evidence 的當日 README。不要另建失去同步的第二套課綱。

語法不足時就在當日做最小補充，不默認舊程式代表已會。卡住時保存最小重現與錯誤，先一次排除一個原因；不得用完整答案蓋過理解問題。未通過標為待補強，翌日可以繼續同一天。
