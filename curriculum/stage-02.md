# 階段 02：逐步建立 Python 量測工具

[課綱](ROADMAP.md)｜[進度](../PROGRESS.md)｜[帶練方式](TEACHING.md)

## 要解決的問題

如何可靠重跑同一工作並比較，讓失敗不會變成虛假的加速？

前置：階段 01 已有可正確重跑的訓練程式。

## 必要觀念

一次 run 是獨立執行；run 內每個 step 是相關的逐步樣本，兩者不能混成獨立重複。JSONL 一行一事件，原始資料保留後再產生摘要。

## 逐步練習

以下按多次教學進行，每次只取一個操作，先講清楚再等待結果。未確認環境前不預寫安裝或訓練命令。

1. 先用 Python subprocess 執行既有訓練一次，保存命令、設定、版本、stdout／stderr 與退出碼。
2. 定義最小 JSONL 記錄：run_id、環境、模型／資料、精度、batch、逐步時間、loss、成功或錯誤。
3. 加入重複執行與暖機；從原始資料計算中位數、分散程度、樣本數與失敗率。
4. 加入逾時、中斷保留與錯誤分類；用錯誤參數及安全的逾時案例驗證。OOM 僅在確認資源影響後測。
5. 加入比較條件檢查：硬體、工作負載、資料、精度與有效 batch；不相符時拒絕純效能回歸結論。
6. 需要多組參數時才加 CLI／設定矩陣；需要跨 run 查詢時才加 SQLite，索引／WAL 深度列延伸。

## 可驗收成果

同規格一條命令重跑；從 JSONL 獨立重算摘要；失敗、逾時和環境不符可見；不以單次最快值報提升。

每個實驗保存目的與假設、環境／輸入、命令、正確性、原始數據、圖與判讀。調整採用或放棄都需理由；用小變化驗證可獨立理解。
