## 中文面試問答（兩題）

1. **問：為何不能靠 __syncthreads 同步整張 GPU？**
   答：它只同步同一 block；跨 block 需分 kernel 或適當專用機制。
2. **問：atomicAdd 是免費的嗎？**
   答：不是，競爭位置會序列化，需依資料分布與工作量評估。
