## 中文面試問答（兩題）

1. **問：shared memory 一定比較快嗎？**
   答：不一定，資料重用不足或同步與 bank conflict 可能抵消收益。
2. **問：barrier 放在條件內要注意什麼？**
   答：條件不能讓同 block 的部分 threads 永遠不參與必要同步。
