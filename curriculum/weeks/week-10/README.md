# 第 10 週：數學、NumPy 與 ML 從零

**固定目標：** 親手完成預測、loss、梯度與更新，不預設機器學習基礎。

**職缺對應：** B ML 效能分析；A 可信量測

**設備：** 一台 CPU VM

**先備：** 前 09 週必要驗收通過；新工具仍從最小例子開始。

|---|---|---|
