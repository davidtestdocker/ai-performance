## 中文面試問答（兩題）

1. **問：Reduce 與 Allreduce 差在哪？**
   答：Reduce 通常只讓 root 得結果，Allreduce 讓所有參與者得結果。
2. **問：collective 能只讓一部分 ranks 呼叫嗎？**
   答：在同一 communicator 通常不行，參與與順序需符合契約。
