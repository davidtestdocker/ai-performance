# 第 19 週：MPI 跨節點平行計算

[固定課綱](../../ROADMAP.md)｜[進度](../../../PROGRESS.md)｜[帶練規則](../../TEACHING.md)

**固定目標：** 親寫 MPI 通訊與歸約並在兩台 CPU VM 驗證正確性和擴展。

**職缺對應：** D 分散式軟硬體調校；A 可信量測

**設備：** 兩台不同 CPU VM；Open MPI

**先備：** 前 18 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | Rank 與 communicator | 輸出含 rank、hostname 與不同 VM 身分，兩端 MPI/程式版本一致。 |
| [D02](day-02/README.md) | Send/Recv 與 deadlock | 資料內容正確，能解釋配對條件與不會死鎖的原因。 |
| [D03](day-03/README.md) | Broadcast、Reduce 與 Allreduce | 各 rank 結果一致且符合容差，不遺漏尾端元素。 |
| [D04](day-04/README.md) | 訊息大小與非阻塞 | 至少五個大小、重複資料與正確性，不能把 API 返回時間當傳輸完成。 |
| [D05](day-05/README.md) | MPI 強弱擴展 | 基準資源數明確，報 S/E、通訊占比與無加速原因，確實跨兩台 VM。 |

## 本週成果與通關

必交：**跨節點 MPI 程式、通訊曲線與擴展報告**。五日驗收全部通過，且能獨立修改小輸入、重新執行與解釋結果，才可進下一週。

實驗報告需有問題、環境、原始資料、正確性、方法、結果與限制。不得要求湊出正向加速；未取得硬體計數器需明列替代證據。第 23 週以原理與診斷設計通關，硬體實測為選修。
