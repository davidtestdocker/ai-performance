## 中文面試問答（兩題）

1. **問：為何小訊息可跑大訊息卻卡住？**
   答：可能依賴 eager buffering，大訊息切換協定後暴露錯誤同步。
2. **問：MPI datatype 為何重要？**
   答：決定元素解讀與資料量，兩端契約不一致會出錯。
