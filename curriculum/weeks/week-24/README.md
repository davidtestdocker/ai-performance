# 第 24 週：四大成果整合與面試驗收

**固定目標：** 獨立重現四大能力成果，識別缺口並能處理陌生變化。

**職缺對應：** A、B、C、D 四項綜合驗收

**設備：** 既有 CPU VM 與一張 GPU，按需分時

**先備：** 前 23 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | 自動化成果重現 | 可追溯提交、版本、命令和原始資料，正確區分成功/失敗/timeout。 |
| [D02](day-02/README.md) | ML 成果答辯 | 能回答為何改、如何驗證、何時失效，報告結果與實際資料一致。 |
| [D03](day-03/README.md) | LLM 成果答辯 | 真正訓練與品質檢查完整，能說明 checkpointing/AMP/SDPA 的不同取捨。 |
| [D04](day-04/README.md) | 分散式成果答辯 | 兩台不同 VM 證據齊全，可解釋 rank/thread/CPU 映射及無加速原因。 |
| [D05](day-05/README.md) | 綜合面試與缺口修補 | 四份成果都達門檻，所有未測限制和未過關項公開；回答每日兩題之外完成口述答辯。 |

## 本週成果與通關

必交：**四份成果報告、重現入口與能力邊界清單**。五日驗收全部通過，且能獨立修改小輸入、重新執行與解釋結果，才可進下一週。

實驗報告需有問題、環境、原始資料、正確性、方法、結果與限制。不得要求湊出正向加速；未取得硬體計數器需明列替代證據。第 23 週以原理與診斷設計通關，硬體實測為選修。
