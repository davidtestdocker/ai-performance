# 第 15 週：從零訓練小型 GPT

[固定課綱](../../ROADMAP.md)｜[進度](../../../PROGRESS.md)｜[帶練規則](../../TEACHING.md)

**固定目標：** 組裝 decoder Transformer 並完成真正的 next-token 訓練。

**職缺對應：** C LLM 訓練效能分析；A 可信量測

**設備：** 一張 GPU；小模型依顯存縮放

**先備：** 前 14 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | Transformer block | 所有預期參數有有限梯度，能手算主要參數量。 |
| [D02](day-02/README.md) | Next-token 目標 | 對齊可人工驗證，loss 不是輸入自我複製造成，padding 不混入有效目標。 |
| [D03](day-03/README.md) | 完整模型與訓練 | 真實 forward/backward/step 全部執行，模型、資料與版本可重建。 |
| [D04](day-04/README.md) | 生成與品質檢查 | 輸出只是質性檢查，訓練報告以 validation loss 等固定指標為準。 |
| [D05](day-05/README.md) | 恢復與小 GPT 驗收 | 恢復誤差有解釋，能從空白說明完整訓練資料流，沒有預填完成數字。 |

## 本週成果與通關

必交：**可恢復訓練的小型 GPT 與學習曲線**。五日驗收全部通過，且能獨立修改小輸入、重新執行與解釋結果，才可進下一週。

實驗報告需有問題、環境、原始資料、正確性、方法、結果與限制。不得要求湊出正向加速；未取得硬體計數器需明列替代證據。第 23 週以原理與診斷設計通關，硬體實測為選修。
