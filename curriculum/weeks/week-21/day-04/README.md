## 中文面試問答（兩題）

1. **問：為何需要 set_epoch？**
   答：讓每輪有一致但不同的洗牌順序，避免每輪重複相同排序。
2. **問：最後不足 batch 有何風險？**
   答：不同 ranks 步數或縮放不一致可能造成等待與錯誤梯度。
