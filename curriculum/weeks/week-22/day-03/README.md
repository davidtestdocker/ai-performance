## 中文面試問答（兩題）

1. **問：為何單機最佳 workers 不一定適用 DDP？**
   答：多 ranks 會各自建立 workers，總 CPU 與記憶體需求增加。
2. **問：如何避免盲目調參？**
   答：先用瓶頸指標縮小變因，再做小範圍受控比較。
