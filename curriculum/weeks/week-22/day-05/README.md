## 中文面試問答（兩題）

1. **問：GPU 空閒先換 GPU 嗎？**
   答：先查資料、CPU、同步與通訊，換 GPU 不一定解決等待。
2. **問：什麼是可用的調校建議？**
   答：包含適用條件、證據、成本、風險與回退方法，而非只有一個參數值。
