## 中文面試問答（兩題）

1. **問：IOPS 和吞吐有何關係？**
   答：相同 I/O 大小時吞吐約為 IOPS×bytes，工作型態不同不能直接互比。
2. **問：direct I/O 等於真實應用嗎？**
   答：不一定，需依應用 cache 與存取模式選擇測試。
