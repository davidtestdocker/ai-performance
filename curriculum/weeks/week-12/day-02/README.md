## 中文面試問答（兩題）

1. **問：self time 和 total time 差在哪？**
   答：self 排除子操作時間，total 包含巢狀操作，直接相加可能重複計算。
2. **問：operator 表夠不夠定位等待？**
   答：常不夠，需 timeline 看相依、重疊與 CPU 等待。
