## 中文面試問答（兩題）

1. **問：non_blocking=True 就會重疊嗎？**
   答：不保證，還取決於記憶體、stream、依賴與硬體。
2. **問：pinned memory 越多越好嗎？**
   答：不是，它占用不可換出的主機資源，過量可能傷害系統。
