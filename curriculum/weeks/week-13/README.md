# 第 13 週：ML 精度、記憶體與調校

[固定課綱](../../ROADMAP.md)｜[進度](../../../PROGRESS.md)｜[帶練規則](../../TEACHING.md)

**固定目標：** 以品質約束比較 AMP、累積與編譯，完成 ML 效能成果。

**職缺對應：** B ML 效能分析；A 可信量測

**設備：** 一張 GPU

**先備：** 前 12 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | 混合精度 AMP | 列 dtype 與硬體支援，精度改變另列品質取捨，不能當完全等價 A/B。 |
| [D02](day-02/README.md) | Batch 與顯存 | 畫吞吐與顯存曲線，不用反覆 OOM 當正常測試，說明有效 batch。 |
| [D03](day-03/README.md) | 梯度累積 | 同有效 batch 參數更新在容差內相符，處理尾端不足累積數。 |
| [D04](day-04/README.md) | torch.compile | 若版本或環境不支援記錄原因與診斷，不捏造提升，計算攤提條件。 |
| [D05](day-05/README.md) | ML 成果驗收 | 報告具原始資料、環境、trace 摘要、品質比較與回退條件，不強求正加速。 |
