## 中文面試問答（兩題）

1. **問：memory-bound 是什麼？**
   答：在目前條件下資料供應限制速度，增加算力未必改善。
2. **問：roofline 能精確預測所有 kernel 嗎？**
   答：不能，延遲、同步、指令混合與快取等因素也會限制表現。
