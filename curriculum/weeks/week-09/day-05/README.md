## 中文面試問答（兩題）

1. **問：面試如何證明找到瓶頸？**
   答：提出時間占比、相符的指標與單一變因實驗，而非只說工具顯示很慢。
2. **問：改善 kernel 卻沒改善總時間怎麼解釋？**
   答：該 kernel 可能占比小，或瓶頸轉移到傳輸、CPU 與同步。
