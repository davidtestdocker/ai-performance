## 中文面試問答（兩題）

1. **問：wall time 可以小於所有執行緒 CPU 時間總和嗎？**
   答：可以，多執行緒同時運算時 CPU 時間會累加。
2. **問：為何不能只測一次？**
   答：排程、快取及背景工作會造成波動，重複測量才能判斷穩定程度。
