## 中文面試問答（兩題）

1. **問：free 很低就要擴 RAM 嗎？**
   答：先看 available、換頁與應用延遲；可回收快取不能當作無法使用的記憶體。
2. **問：major fault 是什麼？**
   答：頁面需從儲存裝置讀入的缺頁，通常比不需磁碟 I/O 的 minor fault 昂貴。
