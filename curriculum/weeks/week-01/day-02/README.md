## 中文面試問答（兩題）

1. **問：load average 是 CPU 使用率嗎？**
   答：不是，它包含可執行與不可中斷等待的工作數，不能直接視為百分比。
2. **問：context switch 一定是壞事嗎？**
   答：不是；需結合頻率、阻塞原因與吞吐判斷切換是否成為成本。
