## 本日用途與必要觀念

職缺對應：A 自動化測試與數據分析；D 分散式軟硬體調校的 CPU 基礎。本日內容支援本週成果「主機盤點、三種負載觀察表與基線報告」，後續沿用，不另做無關展示。

vCPU 是作業系統可排程的邏輯處理器，不保證等於獨占實體核心；快取降低資料存取延遲。

先備：本週入口所列先備。設備：一台 Linux CPU VM。

## 中文面試問答（兩題）

1. **問：vCPU 等於實體核心嗎？**
   答：不一定；VM 顯示的是客體拓樸，還可能和其他 VM 共用實體資源。
2. **問：快取為何影響效能？**
   答：命中可避免較慢的記憶體存取，工作集與存取順序會改變命中率。
