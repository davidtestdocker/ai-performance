## 中文面試問答（兩題）

1. **問：Adam 為何比純權重占更多空間？**
   答：它保存梯度之外的一階、二階狀態，還可能有主權重副本。
2. **問：為何第一步後顯存才增加？**
   答：部分 optimizer state 延遲到第一次更新才配置。
