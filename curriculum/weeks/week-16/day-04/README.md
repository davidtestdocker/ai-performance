## 中文面試問答（兩題）

1. **問：T 加倍成本一定四倍嗎？**
   答：不是，只有部分 attention 操作呈平方關係，其他層與實作也影響總量。
2. **問：能用 nvidia-smi 單點值作峰值嗎？**
   答：容易漏掉短暫峰值，應搭配框架峰值統計與適當監測。
