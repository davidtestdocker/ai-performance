## 中文面試問答（兩題）

1. **問：不同序列長度可直接比 tokens/s 嗎？**
   答：不能當等價工作，attention 成本隨長度改變，需同時列設定。
2. **問：有效 batch 怎麼算？**
   答：等長資料時為 microbatch×累積步數×資料平行 ranks，變長時還要記有效 token 數。
