## 中文面試問答（兩題）

1. **問：int 與 float 有何不同？**
   答：int 表示整數，float 通常用有限精度二進位表示小數，存在捨入。
2. **問：為何欄位名要帶單位？**
   答：可避免不同來源的秒、毫秒與位元組混用而產生錯誤結論。
