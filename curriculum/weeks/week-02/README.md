# 第 02 週：Python 從零與可重現紀錄

[固定課綱](../../ROADMAP.md)｜[進度](../../../PROGRESS.md)｜[帶練規則](../../TEACHING.md)

**固定目標：** 親手建立變數、流程、函式、檔案與錯誤處理能力。

**職缺對應：** A 自動化測試與數據分析；D 分散式軟硬體調校的 CPU 基礎

**設備：** 一台 Linux CPU VM

**先備：** 前 01 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | 變數、型別與單位 | 獨立解釋 100 個樣本耗時 250 ms 為 400 samples/s，避免毫秒當秒。 |
| [D02](day-02/README.md) | 條件、迴圈與容器 | 輸入含 0、負值與正值時，不除以零且每筆都有分類。 |
| [D03](day-03/README.md) | 函式與斷言 | 函式無全域變數依賴，正常值正確，負值與零能被捕捉。 |
| [D04](day-04/README.md) | 檔案與序列化 | 檔案重讀後數值與欄位一致，CSV 有標頭，記錄缺值規則。 |
| [D05](day-05/README.md) | 模組、CLI 與例外 | 他人可用命令重跑；成功回傳 0、缺檔失敗非 0，不吞例外。 |

## 本週成果與通關

必交：**可讀寫 JSON/CSV 的小型實驗紀錄程式**。五日驗收全部通過，且能獨立修改小輸入、重新執行與解釋結果，才可進下一週。

實驗報告需有問題、環境、原始資料、正確性、方法、結果與限制。不得要求湊出正向加速；未取得硬體計數器需明列替代證據。第 23 週以原理與診斷設計通關，硬體實測為選修。
