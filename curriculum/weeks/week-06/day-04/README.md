1. **問：綁核為何可能有幫助？**
   答：可減少遷移與快取失效，但不當綁定也可能加劇競爭。
2. **問：記憶體頻寬飽和後加 threads 有用嗎？**
   答：通常收益有限，應調整存取、資料重用或工作量。
