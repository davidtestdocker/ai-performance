# 第 05 週：C++ 從零與 CPU 記憶體效能

[固定課綱](../../ROADMAP.md)｜[進度](../../../PROGRESS.md)｜[帶練規則](../../TEACHING.md)

**固定目標：** 建立 C++ 資源管理並用工作集、SIMD 與 cache 解釋 CPU 效能。

**職缺對應：** A 自動化測試與數據分析；D 分散式軟硬體調校的 CPU 基礎

**設備：** 一台 Linux CPU VM；perf 權限依環境

**先備：** 前 04 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | C++、vector 與 RAII | 無手寫 new/delete，能解釋 size、capacity 與引用生命週期。 |
| [D02](day-02/README.md) | 類別與最小基準器 | 能逐行解釋建構、成員與回傳，設定和結果分離且可輸出 CSV。 |
| [D03](day-03/README.md) | 工作集與快取 | 固定存取量或清楚正規化，不能因較少工作而宣稱更快；記錄冷暖狀態。 |
| [D04](day-04/README.md) | SIMD 與編譯器報告 | 報告、指令與耗時一起呈現；不能只憑 -O3 宣稱已向量化。 |
| [D05](day-05/README.md) | perf 與 CPU 分析 | 交付 CPU 分析：證據、假說、限制與下一步；無 PMU 不虛構硬體計數器。 |

## 本週成果與通關

必交：**C++ 基準與 cache/SIMD 分析報告**。五日驗收全部通過，且能獨立修改小輸入、重新執行與解釋結果，才可進下一週。

實驗報告需有問題、環境、原始資料、正確性、方法、結果與限制。不得要求湊出正向加速；未取得硬體計數器需明列替代證據。第 23 週以原理與診斷設計通關，硬體實測為選修。
