## 中文面試問答（兩題）

1. **問：stride 為何可能降低效能？**
   答：較少利用每條 cache line，且可能破壞預取與增加 TLB 壓力。
2. **問：cache line 等於單一元素嗎？**
   答：通常包含多個相鄰位元組，實際大小須查硬體而非硬編碼推測。
