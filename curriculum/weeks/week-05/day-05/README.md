## 中文面試問答（兩題）

1. **問：IPC 高就是程式更快嗎？**
   答：不一定，指令數、頻率及等待都會改變總時間。
2. **問：perf 無權限怎麼辦？**
   答：先確認事件與系統政策，使用可用指標並記錄限制，不任意降低全機安全設定。
