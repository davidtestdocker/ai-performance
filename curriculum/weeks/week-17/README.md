# 第 17 週：LLM 單卡調校與標準模型

[固定課綱](../../ROADMAP.md)｜[進度](../../../PROGRESS.md)｜[帶練規則](../../TEACHING.md)

**固定目標：** 比較 SDPA、activation checkpointing 與累積，轉移到標準 Transformer 實作。

**職缺對應：** C LLM 訓練效能分析；A 可信量測

**設備：** 一張 GPU，模型須在現有顯存內

**先備：** 前 16 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | SDPA 與 attention 後端 | 不宣稱所有 GPU 都支援同一後端，實際使用情況與容差有記錄。 |
| [D02](day-02/README.md) | Activation checkpointing | 同工作量與容量收益分開報告，記錄 RNG 與版本設定。 |
| [D03](day-03/README.md) | 累積、AMP 與公平比較 | 每個實驗只有一個主要變因，列吞吐、顯存與品質，至少一個無改善結果如實保存（若有）。 |
| [D04](day-04/README.md) | 標準 Transformer 訓練 | 不重複 shift；能對應自寫模型與標準模型的層，記版本、參數量與訓練曲線。 |
| [D05](day-05/README.md) | LLM 成果驗收 | 自寫與標準模型都真的更新參數，無預設加速目標，明標未做多卡 scaling。 |

## 本週成果與通關

必交：**三份 LLM 調校實驗與標準模型訓練驗證**。五日驗收全部通過，且能獨立修改小輸入、重新執行與解釋結果，才可進下一週。

實驗報告需有問題、環境、原始資料、正確性、方法、結果與限制。不得要求湊出正向加速；未取得硬體計數器需明列替代證據。第 23 週以原理與診斷設計通關，硬體實測為選修。
