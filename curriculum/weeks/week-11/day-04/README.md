1. **問：為何先 overfit 小資料？**
   答：可快速驗證資料、模型、梯度與更新是否接通。
2. **問：DataLoader workers 越多越快嗎？**
   答：不一定，程序成本、CPU 與 I/O 競爭可能降低吞吐。
