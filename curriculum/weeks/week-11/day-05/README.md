## 中文面試問答（兩題）

1. **問：只存模型權重能精確接續訓練嗎？**
   答：未必，optimizer 動量、排程器、隨機狀態等也影響後續更新。
2. **問：為何固定 seed 還可能不同？**
   答：非決定性算子、版本、硬體與執行順序仍可能造成差異。
