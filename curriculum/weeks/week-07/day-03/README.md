## 中文面試問答（兩題）

1. **問：GPU 計算快就代表端到端快嗎？**
   答：不一定，配置、傳輸與啟動成本可能超過節省的計算時間。
2. **問：為何保留 CPU reference？**
   答：提供獨立正確性基準，避免兩個 GPU 版本共享同一錯誤。
