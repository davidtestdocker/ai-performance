## 中文面試問答（兩題）

1. **問：cudaGetLastError 能抓完所有錯誤嗎？**
   答：不能，非同步執行錯誤可能在後續同步或 API 呼叫才回報。
2. **問：為何除錯時同步有幫助？**
   答：可縮小錯誤發生區段，但頻繁同步會改變效能，正式測量需分開。
