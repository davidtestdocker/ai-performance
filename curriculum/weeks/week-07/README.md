# 第 07 週：GPU 架構與 CUDA 從零

[固定課綱](../../ROADMAP.md)｜[進度](../../../PROGRESS.md)｜[帶練規則](../../TEACHING.md)

**固定目標：** 親寫第一個 CUDA kernel，理解執行模型、記憶體與同步。

**職缺對應：** B ML 效能分析；C LLM 訓練效能分析的 GPU 基礎

**設備：** 一張 NVIDIA GPU

**先備：** 前 06 週必要驗收通過；新工具仍從最小例子開始。

| 日 | 主題 | 可觀察驗收 |
|---|---|---|
| [D01](day-01/README.md) | GPU 執行模型與環境 | 能區分 driver 支援的 CUDA 版本與本機 toolkit 版本，保存實際環境。 |
| [D02](day-02/README.md) | 第一個 kernel | 回傳每個元素與 CPU 索引一致，能手算最後一個 block 哪些 threads 不工作。 |
| [D03](day-03/README.md) | Host/device 資料搬移 | 測 1、17、1025 與大陣列，所有 CUDA API 檢查錯誤碼，不漏釋放。 |
| [D04](day-04/README.md) | 非同步、同步與錯誤 | 能定位刻意引入且已修復的越界，不把 CPU launch 耗時當 GPU 執行時間。 |
| [D05](day-05/README.md) | CUDA 正確性驗收 | 冷啟動和穩態分開，所有案例逐元素通過，能從空白補寫索引與邊界判斷。 |

## 本週成果與通關

必交：**含 CPU reference 與錯誤處理的 CUDA 向量加法**。五日驗收全部通過，且能獨立修改小輸入、重新執行與解釋結果，才可進下一週。

實驗報告需有問題、環境、原始資料、正確性、方法、結果與限制。不得要求湊出正向加速；未取得硬體計數器需明列替代證據。第 23 週以原理與診斷設計通關，硬體實測為選修。
