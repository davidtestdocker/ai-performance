## 中文面試問答（兩題）

1. **問：為何需要記憶體註冊？**
   答：讓裝置與系統建立可存取區域及保護資訊，具體機制依平台。
2. **問：RDMA write 後遠端應用一定知道嗎？**
   答：不一定，仍需設計通知、同步與可見性契約。
