## 中文面試問答（兩題）

1. **問：Soft-RoCE 能證明硬體效能嗎？**
   答：不能，可幫助學 API 與流程，不能替代硬體卸載與 fabric 測量。
2. **問：PFC/ECN 可以亂調嗎？**
   答：不行，需理解交換網路和平台管理邊界，先讀計數器與官方設定。
