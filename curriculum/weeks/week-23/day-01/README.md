## 中文面試問答（兩題）

1. **問：RDMA 必須有 GPU 嗎？**
   答：不需要，CPU 主機搭配支援的網卡與網路即可；GPUDirect RDMA 才涉及 GPU 記憶體。
2. **問：裝 verbs 函式庫就能得到硬體 RDMA 嗎？**
   答：不能，還需要支援的裝置、driver 與完整網路路徑。
