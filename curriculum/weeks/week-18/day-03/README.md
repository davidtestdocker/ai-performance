## 中文面試問答（兩題）

1. **問：RTT 高為何影響吞吐？**
   答：相同 window 下能在途的資料受限，確認回傳也較慢。
2. **問：重傳一定是網卡壞嗎？**
   答：不是，壅塞、丟包、路徑或接收處理問題都可能造成。
