## 中文面試問答（兩題）

1. **問：多流結果可代替單流嗎？**
   答：不能，多流可能突破單流 CPU 或 window 限制，需分開報告。
2. **問：Gbps 與 GB/s 怎麼換？**
   答：每 byte 為 8 bits，還需注意協定開銷與單位。
