# 階段 08：乾淨重現與面試交付

[課綱](ROADMAP.md)｜[進度](../PROGRESS.md)｜[帶練方式](TEACHING.md)

## 要解決的問題

如何讓別人重跑，並在追問下說清楚自己做了什麼？

前置：階段 00–07 的實際證據；設備限制項可保留待測。

## 必要觀念

可重現性包含 host driver、容器 runtime、框架、模型、資料、設定與硬體；作品只能證明實際做過的範圍。

## 逐步練習

以下按多次教學進行，每次只取一個操作，先講清楚再等待結果。未確認環境前不預寫安裝或訓練命令。

1. 在現有 GPU VM 的乾淨環境重跑代表案例，核對環境與原始結果；需要新資源前先確認費用。
2. 將成果整理成自動化量測、ML 診斷、LLM 調校、分散式／RDMA 四個入口，每個入口連程式、資料、圖與限制。
3. 每個案例準備問題、假設、證據、變更、代價、限制的五分鐘中文說明。
4. 寫英文摘要並練兩分鐘口頭說明，解釋一張 trace 和一個無效或不確定結果。
5. 做未知 trace、環境漂移、OOM 或慢 rank 的口頭診斷；當場修改小輸入或設定驗證理解。
6. 履歷只寫已發生的實作和量測；兩年以上經歷、企業多 GPU／RDMA 經驗由真實工作證明。

## 可驗收成果

四個成果入口、乾淨重跑證據、中文與英文講解；可追溯履歷敘述，並清楚說明單卡邊界。

每個實驗保存目的與假設、環境／輸入、命令、正確性、原始數據、圖與判讀。調整採用或放棄都需理由；用小變化驗證可獨立理解。

## 面試練習

如何證明加速是真的？如果換 GPU、模型或資料，哪些結論必須重新驗證？
