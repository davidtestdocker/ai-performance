# 模組 11：雲端 GPU 環境重現

[路線](ROADMAP.md)｜目標：讓單 GPU 基準可在另一台機器重建，知道版本、硬體與費用如何影響比較。

[觀念講義](CONCEPTS.md)第 11 節｜[作品成果](OUTCOMES.md)

## 學習大綱

VM/容器/GPU 軟體層 → 可重建環境規格 → 乾淨環境部署 → 版本與數字比對 → GPU 小時及費用。

## 先理解

VM／容器邊界、GPU driver 與容器 CUDA runtime 相容性、映像版本、雲端磁碟與網路、機型配額、GPU 小時與成本。部署規格不能代替實際部署結果。

## 實作

1. 整理單 GPU Linux 環境規格或 IaC：機型、映像、GPU、磁碟、網路、driver、CUDA/PyTorch、容器、資料取得、啟停和清理流程。不要把憑證寫入倉庫。
2. 若使用雲端 GPU，在新機按文件部署，重跑模組 02 的短基準及模組 05 的一段訓練；保存環境差異、失敗修復、GPU 小時與實際費用。若只用本地 GPU，保存可審查的雲端方案和估算，標明未部署。
3. 比較兩次實驗的硬體和軟體版本；若不一致，報告提示不能直接宣稱性能回歸或提升。

## 做完留下的成果

可重建設定、完整環境快照、至少兩個複測入口及雲端狀態說明。雲端部署與成本實績只有實際使用雲端才可標「已驗證」。
